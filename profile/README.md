# SuperDave Lab

Tools and platforms built by **[Dave Koons](https://davekoons.com)** — a staff software engineer in Atlanta with 15+ years in telecom backends, distributed systems, and field-operations software.

Most of what's here shares one bias: **your data stays on your machine.** No accounts, no upload step, no server round-trip for things that don't need one.

## Projects

| | What it is | Stack |
|---|---|---|
| **[LedgerSprout](https://ledgersprout.superdavelab.com/)** | Commercial desktop app that turns bank and credit card statement PDFs into clean CSV, XLSX, JSON, and OFX/QFX — entirely offline. Plugin-style parser registry with auditable auto-detection. *(source private)* | Electron · Node |
| **[LedgerDock](https://ledgerdock.superdavelab.com/)** | Drag in a spreadsheet, get a database table. Infers and lets you edit the schema, then emits a portable `CREATE TABLE` or imports over the database's native connection — no ODBC/OLE-DB driver stack. SQL Server, Postgres, MySQL/MariaDB, SQLite. *(source private)* | Electron · TypeScript |
| **[SiteTrackr](https://github.com/SuperDaveOrg/SiteTrackr)** | Open-source field-operations maintenance platform: dynamic ticket templates, site metadata, visit logging, attachments, role-based permissions. | Fastify · React PWA |
| **[Nexpill](https://github.com/SuperDaveOrg/Nexpill)** | Local-first medication tracker with precise timing logic, taper support, and fully offline persistence. | TypeScript · IndexedDB |
| **[LogSmith](https://github.com/SuperDaveOrg/LogSmith)** | Fast local log analyzer — summarizes delimited logs, groups recurring error patterns, filters by level and time window. | C# · .NET |
